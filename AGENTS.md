# Repository instructions

- Treat `README.md` as the canonical project guide.
- Whenever a change affects setup, controls, combat rules, balance, audio, responsive behavior, file structure, story, status, or roadmap items, update the relevant README section in the same change.
- For meaningful release-style changes, update the README version and last-updated date.
- Preserve the dependency-free HTML, CSS, and JavaScript setup unless the user explicitly approves a tooling change.
- Keep the game usable with touch alone and test desktop plus 390 px and 320 px mobile viewports after UI changes.
